# Limites et verification

Le README qualifie explicitement cette bibliotheque de prototype academique non pret pour la production.
La concision ne suffit pas : extractabilite, hiding et liaison au degre doivent etre preserves.
Les schemas reposent selon le cas sur pairings, logarithme discret, codes ou hachage.
Le batching amplifie l importance d un transcript correctement domaine-separe.
Ce parcours repose sur le trait PolynomialCommitment et les modules KZG, Marlin, IPA et multilineaires.
Aucune installation, compilation, benchmark ou execution nouvelle n a ete effectuee.
Les performances et proprietes ne sont donc pas revendiquees comme mesurees ici.
Pour verifier, consulter les tests du crate poly-commit et les articles references par le depot.
